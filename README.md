# Almacén de Flotas

Web de estudio para el parcial de Gestión y Operación de Flotas (temas 1A–2C).

Todo va en un único `index.html`, sin dependencias ni compilación. Para abrirla en local basta con hacer doble clic en el archivo.

## Publicarla con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `.nojekyll` y este `README.md` a la rama `main`.
3. Ve a **Settings → Pages**. En **Source** elige *Deploy from a branch*, la rama `main` y la carpeta `/ (root)`. Pulsa **Save**.
4. Al cabo de un minuto la web estará en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.

## Qué incluye

- Seis temas, cada uno con estas pestañas: Estudio (tus apuntes contrastados con los de la profesora), Mapa, Test, Ejercicios, Escritas y Repaso.
- 305 preguntas tipo test de nivel Normal y Difícil, con corrección y explicación al momento. Se pueden hacer una a una con el teclado o en lista.
- Ejercicios con calculadora paso a paso y un modo «Hazlo tú». Se pueden hacer con los datos originales o con números nuevos.
- Un simulacro cronometrado con penalización.

El progreso se guarda en el navegador (`localStorage`), así que es distinto en cada dispositivo.
